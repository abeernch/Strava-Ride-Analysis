# Contributing

Contributions are welcome when they improve parsing, reliability,
documentation, or analysis workflow.

## Good changes

- Support for more TCX activity types
- Better filtering, reporting, or validation
- Additional documentation for the analysis pipeline
- Example outputs that show the next analysis step

## Before opening a pull request

1. Keep the CLI backward-compatible unless a breaking change is documented.
2. Prefer the Python standard library when it is enough for the task.
3. Test with a small folder of TCX files before changing the parser.
4. Document any new flags or output folders in the README.
